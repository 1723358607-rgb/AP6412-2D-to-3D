开始：检查当前分支、工作区未提交内容和最新 main；读取必读文件；说明本轮任务、涉及文件与依赖。保留已有修改，不覆盖队友工作。

结束：运行相应检查；列出通过、失败、未执行的项目；给学生写具体手动验收步骤；保存实际可取得的完整 AI 记录及价值索引；提交个人分支并通过 PR 整合。

`main` 保存已整合的公共版本；个人分支保存真实贡献。保留有意义的提交和 PR/merge 历史。不要伪造队友提交、评审、聊天记录、测试结果或已完成状态。
